# PPT-agent

在 Windows 桌面版 PowerPoint 的“开始”选项卡打开 **PPT-agent**，通过右侧聊天栏修改当前演示文稿。输入框上方显示当前页和所选形状，例如 `Slide 5 of 21 · Title 9`。输入完整指令后，下一行显示指令要操作的页面。发送时读取当前选择，指定页码时定位到该页。

## 在 Windows 试用加载项

1. 安装 Node.js 22 LTS 或更新的 LTS 版本、Python 3（含 Windows 的 py 启动器）及桌面版 PowerPoint。
2. 下载并解压仓库，双击 **Start-Addin.cmd**。首次启动会安装依赖、启动本地 HTTPS 服务并通过 Office 开发工具旁加载。若系统询问是否信任 localhost 开发证书，请核对来源。
3. 在 PowerPoint 中点击 **开始 → PPT-agent**。如开发工具打开了空白演示文稿，可先在其中测试，再在自己的汇报中打开加载项。编辑直接作用于打开的文稿，请用副本试用。如在现有汇报的工具栏尚未看到按钮，可先在开发工具打开的演示文稿中验证。结束时可在 addin 目录运行 `npm stop`。
4. 选择标题框，输入 `把这个标题改成品牌考虑度`。页码和对象定位需要 PowerPointApi 1.5；原生表格内容编辑需要 1.8；行标签改色需要 1.9。页面会提示不支持的操作。

## 侧边栏指令

| 操作 | 示例 |
|---|---|
| 修改当前选中的文本框 | 把这个标题改成品牌考虑度 |
| 按编号写入单格 | 把第5页第3行第2列改为待复核 |
| 按第一列标签写入单格 | 把第17页“Base”这行第2列改为100 |
| 改第一列非空行标签颜色 | 把第17页的行标题全部标红 |
| 对齐已有表，补空并报告差异 | 交叉表补空 第17页 |
| 从连续区域生成新表 | 区域A1:C5，筛选城市=上海，按品牌分组对销量求和，按销量降序，选取品牌、销量，填入第2页新表格 |

Excel 指令先展开“Excel 交叉表”，选择 .xlsx 文件和工作表。普通区域的第一行须为列名，筛选、分组、排序、选列可依次省略。多张原生表并存时，请切到该页并点选目标表格。

**问卷交叉表**要求目标表第一行为品类、第一列为行为。源表第一列含题号（如 B6B8E57_01）和品类名，题名上方有 Base 和 Total 表头，下方是行为明细。选择题号前缀，可以输入项目别名，如 `Hair=洗发护发、头发护理`。源表整百分比数值按百分点显示，带百分比格式的数值按 Excel 比例换算，Base 按整数显示。工具按标签规划全部修改，列出已有差异和来源地址，写后重新读取。遇到缺项或歧义会提示原因。

**可选 DeepSeek**：在 Windows 为当前用户设置环境变量 `DEEPSEEK_API_KEY`，重启服务；在指令前加 `DeepSeek `。程序只向模型发送该前缀后的文字。候选指令会显示在输入框，核对后发送。表格和演示文稿数据留在本机。确定性指令无需 API Key。

## 独立文件模式

双击 **Start.cmd**，或在仓库目录运行 `python -m pip install -r requirements.txt` 和 `python main.py`。输入指令后按提示选择源文件，回车使用自动生成的示例。支持标题文字、统一字体和字号、文字替换及从 Excel 按位置填表。每次编辑另存副本；按位置填表会覆盖对应范围，与侧边栏的交叉表补空行为不同。

## 验证

`python -m unittest discover -s addin -v` 检查交叉表匹配；在 addin 目录运行 `node --test test-pane.cjs` 检查指令和对象定位。上线前应在实际 Office 版本及项目工作簿上验证；开发旁加载不代表已发布到 Office 商店。

独立模式也可以输入 `交叉表补空 "需要贴的数据.xlsx" "品类搜_合并数据" B6B8E57 第17页`。相对路径从 PPT 所在目录解析；自定义品类别名请使用加载项界面。没有待补空格时只打印核对结果。


## DeepSeek 自动查表补空

1. 在 Windows 开始菜单搜索“编辑账户的环境变量”，新增用户变量 `DEEPSEEK_API_KEY`，值为你自己的完整 Key。关闭旧加载项服务，重新运行 Start-Addin.cmd。Key 仅由本机 Node 服务读取。可选变量 `DEEPSEEK_MODEL` 用于指定支持工具调用的模型，默认 deepseek-v4-pro。
2. 在侧边栏展开 Excel 交叉表，选择 .xlsx，勾选 **DeepSeek 自动查表补空**。输入“用这个 Excel 补齐第17页，保留已有值，告诉我差异”。这个模式自动查找工作表和题号；界面上手填的工作表和题号供固定指令使用。
3. 服务通过多轮工具调用向模型返回目标标签、候选来源和匹配统计。题块需符合这里描述的 Base / Total 布局。如果多组数据都匹配，侧边栏会显示工作表和题号供选择。发送时锁定目标，写入前重读，写入后核对整张表并列出 Excel 来源地址。
4. 未勾选时仍可使用固定指令；原有的 DeepSeek 前缀用于生成候选指令。自动查表目前处理单页原生表格的补空和冲突报告，更复杂的开放分析仍需增加工具。
